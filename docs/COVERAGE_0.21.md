## 新增接口的使用限制

- 扫掠轮廓坐标属于 Creo 自动生成的轨迹起点截面坐标系。`creo_set_sketch_dimensions` 的 `sketch` 可引用扫掠标签，编辑 `dimensions` 中命名的尺寸。当前只提供恒定截面。
- 镜像不接受 `kind:feature`；Toolkit 的几何/零件镜像与特征子树镜像有不同支持范围。保留原体以外的选项仍需验证。
- 钣金首壁目前使用一条开放直线作为驱动轮廓，`depth` 为沿草图法线的长度。转换面取薄壁实体最大的平面；闭合、弯曲和多段首壁未验证。树中保留草图、薄壁拉伸和钣金转换，首壁不是单一的传统 Wall 特征。
- 装配来源须为本服务登记、已保存且无待完成任务的零件/钣金模型。插入时复制来源的版本快照；后续修改来源不更新组件。子装配在提交前被拒绝。
- 旋转采用 XYZ 欧拉角，依次绕 X、Y、Z；平移使用装配坐标系毫米值。`creo_component_placement` 替换原有约束为固定定位。
- `mate`、`align`、两种偏置、`insert`、`csys` 的参数接口已定义；实机验证仅覆盖三平面对齐、命名组件基准引用和对齐偏置。其他约束和默认放置尚需验证。
- 通用 Element Tree 接口仅能创建 SDK 实际支持且完整有效的定义；它不是“任意 Creo 操作”接口。

## 为什么不能标记为全覆盖

本机 Creo 10 Toolkit 的 `Features_create.html` 明确说明并非所有特征类型都能直接通过 Toolkit 创建。PTC 从 [Creo 11.0.0.0 起增加边界混合的专用 Element Tree 支持](https://support.ptc.com/help/creo_toolkit/protoolkit_pma/r11.0/usascii/creo_toolkit/protoolkit_rln/Support_for_Boundary_Blend_Feature_11000.html)。这并不等于所有普通放样都必须升级；本项目的普通放样路径仍未完成，当前保留接口不应当作可用能力。

后续优先补齐普通放样，并扩展变截面扫掠、特征镜像、钣金成形和子装配等。只有通过原生再生、尺寸修改和保存重载检查后才能启用新功能。0.21 发布说明保留这些未完成项。
