# BUG-195：包围盒面细分误差披露、空件平面报错与边选择器歧义提示

类型：缺陷。优先级：P2。

分类：**已有修复但待验收**。0.47.0 交付包围盒误差披露、空件平面报错与边选择器歧义提示；Creo 10 实机与 4548 项单测通过。 [发布记录](../validation/RELEASE-0.47.0.md)

## 来源与现象

2026-11-26 外部 0.45.1 / Creo 10.0.0.0 反馈 §3、§4、§6、§14.3–14.5：

1. **§3**：`solid_bounds.h` 将 `bounding_box_source` 改为 `solid_face_tessellation` 后，圆柱/球面按内接多边形细分产生约 `target_chord_height_mm`（`0.001 mm`）的单侧内缩，但 `bounding_box_status` 仅报 `state: "measured"`，未披露方法误差上界。
2. **§4**：空零件/空钣金件（`surfaces=0`）上用 `{kind:'plane', normal, offset}` 报 `0 candidate surface(s)`，却仍推荐 `{kind:'plane', normal, offset}`，未按空件分支提示 `{kind:'datum_plane', axis, offset}` 或 `{kind:'datum_plane', id}`。
3. **§6**：`geometry_selectors.cpp` 在多边歧义拒绝时未列出各候选边的 `adjacent_surfaces` 与已有的 `on_face` / `ambiguity:'nearest'` 出口。

## 范围与验收

1. `native/solid_bounds.h`：`bounding_box_status` 在测量成功时增加 `measurement_method: "tessellated"`、`method_error_bound_mm: target_chord_mm` 与 `error_bound_direction: "inward"`。
2. `native/generic.cpp`：`kind == "plane"` 且无实体面（`candidates.empty()`）时给出空件分支错误提示，明确指向 `datum_plane`（`axis+offset` 或 `id`）。
3. `native/geometry_selectors.cpp`：多边歧义报错附加各命中边的 `adjacent_surfaces` 并提示 `on_face:{kind:'surface',id:N}` 与 `ambiguity:'nearest'`。
4. 补充单元测试、编译原生执行器并在 Creo 10 实机验证三项改进（含空钣金件 `datum_plane` `axis+offset` 实测）。
