# BUG-153：样条切除与失败证据

分类：**已有修复但待验收**。优先级 P1。显式近似与诊断交付于 0.36.0，精确切除待调查。

来源为 [0.35.5 原始反馈](../validation/feedback-0.35.5-2026-11-22/originals/save-and-loft.md) §3、§9.1，关联 [BUG-150](BUG-150.md) 与 [FEAT-066](FEAT-066.md)。在 Creo 10 / Toolkit 42 用封闭 B 样条轮廓和等形折线作对照，检查原生轮廓、实体体积及回滚。验证 compact 保留有限量的关键诊断，full 保留原报告。

精确样条重现闭合轮廓去料为零，回滚通过。匹配 SDK 的 `ProArray` 写入后仍复现。新增显式 `approximation_segments` 让调用方选择原生执行器按点采样后用折线建模。失败回执增加取自原生草图的闭合、开放端点和 B 样条数量。compact 裁剪后保留有界关键读数。

Creo 10 实机 21 段近似与同一输入手工折线的去料体积一致，见[本次验收记录](../validation/feedback-save-loft-2026-11-23.md)。

2026-11-28（`0.50.0` 基线 Creo 10.0.0.0 通用闭环 B 样条切除基准，模型 `1dc0e7d2879e4977b75d880849708eb2` 等四件对照，理论去料 `1049.9997 mm³`）：精确 `b_spline` + 闭合直边直接切除成功并实测去料 `1049.9832 mm³`（误差 `-0.0165 mm³`，`saved_file_reloaded_and_verified=true`），显著优于显式折线近似 `poly_16`（`-4.88 mm³`）、`poly_32`（`-1.22 mm³`）与 `poly_64`（`-0.30 mm³`）；`approximation_segments` 仍保持显式按需选用。
