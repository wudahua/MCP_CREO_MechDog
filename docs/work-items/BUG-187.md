# BUG-187 偏移基准面法线与草图 v 轴显式可控

分类：**已有修复但待验收**。缺陷，P0，目标版本 0.44.0 / 0.47.1。

来源为 [0.43.1 反馈](../validation/feedback-0.43.1-2026-11-24/originals/datum-plane-normal-sketch-axis-flip.md) §1 与 [0.46.1 复验反馈](../validation/feedback-0.46.1-2026-11-26/SOURCE_MANIFEST.json) §1。报告用 `datum_plane` 在平行 XZ、偏移 −30 处建面，回读法线为 `(0,1,0)`，而 capabilities 把 XZ 帧定义为 `normal=(0,-1,0)`；草图 `v = n × u` 随之变成 −Z，5 张草图 z 反号、5 个拉伸方向也反，特征与作业仍报成功，只能靠体积和包围盒发现。

当前 `SketchOp.plane` 的字典形式只有 `u_axis` 入口，v 轴只能由法线推出；`PlaneOp` 没有 `flip` 或显式法线控制；草图回执虽回显 `normal/u_axis/v_axis`，但请求帧与实际帧不一致时没有警告。

## 范围

- `SketchOp.plane` 字典接受可选 `v_axis`；同时给出 `u_axis` 与 `v_axis` 时校验两者为单位向量且正交，并由叉积确定法线；只给 `u_axis` 时保持现有推导。
- `PlaneOp` 增加显式 `flip`，只翻转新建基准面的法线方向，不改变面位置。
- 草图成功回执在请求帧与实际 `v_axis` 不一致时给出 warning，不改变成功状态。
- capabilities 与 `SketchOp.plane` 描述注明：偏移面法线取决于支持面，建面后必须回读。

## 验收

本机 Creo 10 / 匹配 SDK 复现报告的平行 XZ、offset −30 用例：回读法线；显式 `v_axis=[0,0,1]` 后草图不再 z 反号、拉伸方向与设计一致；体积、包围盒与解析值一致；`saved_file_reloaded_and_verified=true`。失败路径保持 revision 不变并回滚。默认 `XY/XZ/YZ` 字符串平面的行为零变化。

## 不做

不自动为 `{kind:'plane',normal,offset}` 合成 helper 面；该能力另行评估，不在本卡承诺。

## 本机 Creo 10 实测证据（2026-11-24）

- 实现：Python `PlaneOp.flip`、`SketchOp.plane` 字典 `v_axis`/`flip` 正交校验，原生 `datum_plane` 翻转与 `sketch_frame` 显式 `u_axis`+`v_axis` 按叉积 `u_axis × v_axis` 确定法线。
- 实机（Windows x64 / Python 3.12.10 / Creo 10.0.0.0 release 42，报告 `build/dev101_p0/acceptance.json`，SHA256 `65ddc053df023774092beec051a372dbecd17646f170f3573c7fda2ef4ede03e`）：
  - 正例（作业 `0046cec9254f4f3f9d2d12cb2e1b93b8`，模型 `451a329568da4e788615c8c5dd806e27`，rev 1）：平行 XZ 偏移 `-30` 建 `p_norm`/`p_flip`，在 `p_norm` 上显式 `u_axis=[1,0,0]`、`v_axis=[0,0,1]` 建 `10×20` 矩形并拉伸 5 mm；实测 `sketch_v_axis=[0,0,1]`、`sketch_normal=[0,-1,0]`、包围盒 `[0,-35,0]–[10,-30,20]`（Z 不再反号）、体积 `1000.0 mm³`、`saved_file_reloaded_and_verified=true`。
  - 负例（作业 `4e5d44b7fca542798744641719627ed3`）：`v_axis=[0,1,0]` 平行于支撑面法线时原生拒绝并回滚保持 rev 1。

## 2026-11-26 0.47.1 根因修复与本机 Creo 10 三组实机验收

- 实现：`native/generic.cpp` 中 `offset_plane` 对主基准面（`axis="x"|"y"|"z"`）的非倾斜偏移默认对齐至 `capabilities.frames` 规范法线（`YZ=+X`、`XZ=-Y`、`XY=+Z`）并发布 `datum_plane` 的 `plane_frame`；字典草图面未显式传 `v_axis`/`flip=true` 且实际法线与主平面规范法线相反时输出 `frame_warning`（`code="frame_mismatch"`）；`compact_sections.py` 保留 `plane_frame`/`frame_warning`；`creo_capabilities` 新增 `frames_note`。
- 实机（Windows x64 / Python 3.12.10 / Creo 10.0.0.0 release 42）：
  - 默认 XZ 偏移 `-30` + 默认字典草图（作业 `2df364a78c39444db9118890cb015a5d`，模型 `41521fc98820429f90410125ec162338`）：`plane_frame.normal=[0,-1,0]`、`canonical_frame_aligned=True`；草图 `normal=[0,-1,0]`、`v_axis=[0,0,1]`、无告警；拉伸体积 `5600.0 mm³`、包围盒 `[-20,-37,-10]–[20,-30,10]`、`saved_file_reloaded_and_verified=True`。
