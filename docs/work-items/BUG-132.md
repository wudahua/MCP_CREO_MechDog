# BUG-132：圆柱面被拆成两个半面导致 insert/concentric 选择器无法唯一命中

## 当前摘要（2026-11-26 台账复核）

分类：**已有修复但待验收**。优先级 P1。0.27.0 已交付报错分型和显式同轴选择。Creo 12.4 等价夹具已验证默认歧义拒绝、`coaxial:"any"` 插入配合和保存重载。取得 Arm7 原模型后，优先在 Creo 10 核对两个半圆柱面的 ID 与类型、同轴约束及保存重载。剩余验收未排期。

## 原案与离线排查（2026-11-16）

来源：0.26.0 外部报告 P6、P3-4、P3-5。证据为 Creo 10.0.0.0 实机回执，本轮只改源码与离线测试，未连接 Creo、未编译原生。

TXT 的 `[B-MENT]` 只给整圆柱的圆心、轴与半径，不含「哪一半」的信息；native 把同一个圆柱拆成两个半面：

| 零件与特征 | native 面 | 结果 |
| --- | --- | --- |
| base R27.5 内孔 | id 198（x≥0）、200（x≤0） | `center_mm+radius_mm+axis` 命中 2 面 → 拒绝 |
| hom R27.5 外圆 | id 57、59 | 同上 |
| hom R25 内孔 | id 96、98 | 同上 |
| hom R3.5 凸台孔 | id 224、226 | 同上 |

同一 hom_1 输入在 2 组件探针中 9.4 秒失败：`geometry_selector surface filters matched 2 faces (ids 198, 200)`；23 组件计划中同一 op 挂死（见 [BUG-131](BUG-131.md)）。作业 `303bd661` 中 hom_1 的两条约束（concentric insert + coincident mate，assembly/model 两种坐标空间与 `assembly_component` 标签）已成功提交，说明链路本身可用，剩下的是唯一性与报错语义。

两个明确误导：

1. 消歧点 `points_mm` 落在圆柱端面平面时会报 `selector resolved to surface type 34, but concentric/insert needs a real cylinder (PRO_SRF_CYL); add radius_mm ...`，但调用方已经给了 `radius_mm`；真实原因是消歧点命中了平面。
2. 省略 `assembly_component` 时组装侧选择器在 0 个面上解析，报 `matched none of the 0 planar/cylindrical model faces`，不提示缺少标签字段。

## 本轮离线交付（2026-11-16，P6 / 批次 E）

1. **报错分型**（`native/geometry_selectors.cpp`）：
   - 零命中：保留候选面数量与容差，并明确 `radius_mm` 只过滤圆柱半径、不是面类型过滤器。
   - 多个同类面：`ids 198 (cylinder), 200 (cylinder)` 逐项带类型；提示同轴圆柱可能拆成多片，需 `points_mm` 落在单片的 bbox 内、显式 `{kind:'surface',id:N}`，或（仅 insert/concentric）`coaxial:"any"`。
   - 类型不符：同方向/同锚点但类型不可用的候选单独列出 `ids ... (plane)`，说明 `radius_mm/center_mm` 需要圆柱，消歧点落在端面平面时会解析到平面。
   - 诊断新增 `matched_types`、`type_rejected_ids`、`type_rejected_types`。
2. **解析后类型复核**（`native/advanced.cpp` `require_constraint_surface_type`）：insert/concentric 拿到非圆柱时，若选择器已带 `radius_mm`，不再重复建议补 `radius_mm`，而是指出 `radius_mm` 非类型过滤器、消歧点可能落在端面平面，并给出移点、显式 id 或 `coaxial:"any"` 三条出口。
3. **缺字段预检**（`src/creo_mechdog/schema.py` `AssemblyConstraint`）：组装侧 `assembly_reference` 为 `geometry_selector` 且未给 `assembly_component` 时，在 Python 准入直接拒绝并点名缺失字段；装配本身没有实体面/边，选择器必然枚举到 0 项。组件侧选择器不受影响。
4. **显式 `coaxial:"any"`**：
   - schema 只接受 surface 选择器、值必须为 `"any"`、且必须同时给 `radius_mm` 与 `axis`；
   - 仅 `insert`/`concentric` 约束可用；`mate`/`coincident`/`align`/`csys`、round/chamfer/flange 锚点与其他操作一律拒绝；
   - 原生仅在「多个命中且全部为圆柱」时生效，按最小 id 确定性选取，诊断记录 `coaxial_any`、`matched_ids`、`matched_types`；
   - 默认仍要求唯一面，未放宽既有语义。
5. **测试**：`tests/unit/test_geometry_selectors.py` 与 `tests/unit/test_assembly_constraint_semantics.py` 更新/新增合同与源文本回归，共 39 项通过；既有选择器与约束测试同步补 `assembly_component`。
6. **原生构建修复**：2026-11-17 本机 Creo 12.4 实机构建首次编译 P6 改动时，`bool near` 被 Windows 头文件的 `near` 宏展开（`C2513`）。局部变量已改为 `near_anchor`/`inside_box`，`bridge.build_native()` 随后通过；这不是行为变化。

本轮离线阶段未编译原生；2026-11-17 本机 Creo 12.4 实机复测时已执行 `bridge.build_native()`，修掉 `near` 宏冲突后编译通过。`coaxial:"any"` 的几何等价性仍只在源码层成立：真实半圆柱上的 insert 求解、保存重载与 revision 必须由目标机验证后再讨论是否放宽默认。

## 实机验证：报错分型（2026-11-17，本机 Creo 12.4.0.0）

用 100×80×20 mm 方块 + R27.5 通孔复现拆半：孔壁被报成 **id 102 / 103 两个半圆柱**（type 36，竖直轴，bbox 各占一半）。驱动 `build/bug132_live_probe.py`，报告 `build/live_bug132/20261117T090714_af80ee73/report.json`（SHA256 `7136b549b4b9d779842d4278b6e4e47f04b14852ed91925be1cf8777b86c582c`），`passed=true`。

| 用例 | 实际报错 |
| --- | --- |
| 多命中 | `matched 2 faces (ids 102 (cylinder), 103 (cylinder)); ... Add points_mm that lies inside exactly one piece's bbox ... or (insert/concentric only) set coaxial:'any'. radius_mm filters a cylinder's radius; it is not a surface-type filter.` |
| 类型不符 | `matched no usable face, but 2 candidate(s) ... (ids 53 (plane), 58 (plane)); radius_mm/center_mm require a cylinder and radius_mm is not a type filter. A points_mm anchor that lies on a cylinder's planar end face resolves to that plane ...` |
| 零命中 | `matched none of the 8 planar/cylindrical model faces (tolerance_mm=0.010000, axis_tolerance_deg=0.500000); ... radius_mm filters a cylinder's radius; it is not a surface-type filter.` |

三项均按新措辞输出，且作业 `effect_status=rolled_back`，没有创建特征。**未验**：真实半圆柱上的 `coaxial:"any"` insert（需要装配与销件）；本轮只验证了拆半与选择器报错分型。

## 实机验证：coaxial insert 与保存重载（2026-11-17，本机 Creo 12.4.0.0）

新建 base（100×80×20 + R27.5 通孔，孔壁 102/103）与 pin（R27.4×60，对称），在装配中插入两次：

- **默认 insert**（装配侧 `center_mm+radius_mm+axis`，不带 `coaxial`）：作业 `failed`、`effect_status=rolled_back`，报错列出 `ids 102 (cylinder), 103 (cylinder)`，并提示 `points_mm`、显式 id 或 `coaxial:"any"`。
- **`coaxial:"any"`**（装配侧与组件侧都带）：insert + mate 作业 `succeeded`、`effect_status=committed`；组件 `underconstrained=false`；销轴与孔轴重合（translation x/y≈0），轴平行 Z（旋转矩阵第三列 ≈ `[0,0,±1]`）。对称销被 mate 翻转并放在孔上方（z=50），因此这里只断言轴共线，不断言具体轴向位置。
- **显式保存重载**：`creo_save_model` revision 5→6，`saved_file_reloaded_and_verified=true`。

驱动 `build/bug132_insert_live_probe.py`，报告 `build/live_bug132_insert/20261117T012115_a6bb73/report.json`（SHA256 `548066c4bd70758568f26fa066599eb8ad7460bf9b9261c46bd5d8be1783532b`），`success=true`。**仍未验**：Arm7 原半圆柱、Creo 10 目标机。

## 范围

1. **报错分型**：零命中、多个同类面（列出 id 与类型）、命中类型不符（列出候选类型分布）三种分别措辞；说明 `radius_mm` 不是类型过滤器。
2. **Python 预检**：组装侧 `assembly_reference`（报告原文写作 `component_reference`）需要 `assembly_component` 说明时，在提交前直接指出缺失字段，不落到原生「0 个面」。
3. **同轴多面**：显式选项 `coaxial: "any"`（仅 `insert/concentric` 可用），默认仍要求唯一；几何等价性须在目标机用真实半圆柱验证后再讨论是否放宽默认。
4. `mate/coincident` 的平面要求不变，不能因为放宽 insert 而放松。

## 验收

- 本机实机（Creo 12.4，等价夹具）：R27.5 通孔拆半 102/103；默认 insert 拒绝并列出 id/类型；`coaxial:"any"` insert+mate `committed`、轴共线；显式保存重载 revision 5→6。**已完成**。
