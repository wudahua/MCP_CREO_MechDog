# BUG-145 桌面启动在 Unicode 路径下失败，清理错误掩盖回执

分类：**已有修复但待验收**（0.35.6 交付修复）

类型：缺陷。优先级：P1。目标版本：未排期。

旧版以 UTF-8 写入 CMD，但按控制台代码页解释内容。0.35.4 仍生成 CMD；旧反馈的 -4 首因仅适用于该报告的对照场景。Windows / Python 使用空格、中文、百分号及 shell 字符的工作目录和参数，验证字节输出、退出码、无许可值落盘、清理失败的已完成回执。真实 Explorer / Creo Toolkit 连接另验。

来源：[本批反馈计划](../archive/development/0.35.0-FEEDBACK-PLAN-2026-11-21.md)。

离线实现与验证：Explorer 直接启动隐藏的 Python helper，使用 JSON 保留 Unicode 参数和工作目录。基线 ASCII 返回 0，中文脚本参数返回 2，中文临时父目录无回执；新实现通过真实 Explorer 的 Unicode 对照及 17 项桌面启动和连接提示回归。清理失败只记录诊断，实际 Creo Toolkit 探针及外部宿主待验。
