# BUG-120：Creo 10 边界混合元素树不可提取，`surface_loft` 只能回滚

## 当前摘要（2026-11-13）

分类：**部分交付 0.23.2**（诊断与能力披露已交付；剩余：模板 XML / 精确曲面导入未排期）。类型：缺陷/兼容性。优先级：P1。目标版本：0.23.2（诊断子项）。

来源：`C:\Users\Administrator\Downloads\0.23.0` 四份报告，映射见 [归档 MAPPING](../validation/feedback-0.23.0-2026-11-12/MAPPING.md)。

结论：Creo 10 上 `ProFeatureWithoptionsCreate` 返回 0 并留下 incomplete 的边界混合空壳，但 `ProFeatureElemtreeExtract` 返回 `-18`，两个提取器均拒绝，`ProElemtreeVerify=-2`；GUI 手工创建同类特征也失败。这不是 Python 计划、曲线引用或门禁编译问题，而是该宿主内核不支持回读。0.23.2 只交付诊断、回执字段和能力披露，**不宣称 Creo 10 运行期可用**。

剩余范围：Creo 12.4 导出模板 XML + `ProElemtreeFromXMLCreate` 替换曲线引用；或 STEP/IGES 精确曲面导入评估。两者都未排期。

## 现象与证据

- 0.23.1 报告：`create_code=0`、`extract_code=-18`、`feature_incomplete=true`、`release_numeric=42`。
- 0.23.0 报告：13 个候选截面全部 `-18`；`ProFeatureElemtreeExtract` 与第二提取器均拒绝；`ProElemtreeVerify=-2`；GUI 手工特征同样 `-18`。
- 0.23.0 报告 Q1 结论：没有可提取形态的边界混合特征。

## 0.23.2 已交付（诊断）

- `native/surface_loft.cpp`：创建成功后、提取前读取 `ProFeatureIsIncomplete`，回执新增 `feature_incomplete` 与 `feature_incomplete_code`；不在 12.4 上用它提前拒绝。
- 提取失败：回执新增 `extract_unsupported=true`、`kernel_completion="unsupported"`、`kernel_evidence={release_numeric, create_code, extract_code, feature_incomplete}`；错误文本包含 `SURFACE_LOFT_EXTRACT_UNSUPPORTED`、两个 code、完整性状态与回滚说明。
- 提取成功：`extract_unsupported=false`、`kernel_completion="supported"`。
- `bridge.py`：按 worker SHA 将最近观测写入 `build/toolkit_health.json` 的 `surface_loft_runtime`；状态探针不覆盖该键；观测与 worker 不匹配时投影为 `unknown`。
- `creo_session_status` 与 `creo_capabilities` 的 `worker_build_identity.features.surface_loft` 披露 `kernel_completion` 与证据；`available`/`enabled` 与准入判断不变，不预拒绝。
