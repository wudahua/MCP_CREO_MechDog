# DEV-107 Windows CI 中文输出编码

分类：**已交付 0.48.2**。P1。 [发布记录](../validation/RELEASE-0.48.2.md)

Windows CI 在 `tools/test_update_check.py` 输出包含中文的 JSON 摘要时使用 cp1252 编码，抛出 `UnicodeEncodeError`，导致 `tools/dev_check.py` 在离线检查阶段退出，全量单测未启动。[主干失败记录](https://github.com/wudahua/MCP_CREO_MechDog/actions/runs/45969588668/job/140406458284)

验收使用 GitHub 托管 Windows runner 的现有工作流。离线检查全部通过，随后全量单测执行完毕，上传的开发检查和单测报告均记录成功。

Windows / Python 3.12 独立工作树复验同一条 `tools/test_update_check.py --network-failure` 命令：将输出捕获到管道，cp1252 下以 `UnicodeEncodeError` 退出（退出码 1），启用工作流设置的 `PYTHONUTF8=1` 后返回 0，标准输出可按 UTF-8 还原为含中文的成功 JSON。

在修复提交 `c3d7875d` 上运行 `tools/dev_check.py`，GitHub 托管 Windows / Python 3.12 的三项离线检查通过，全量单测通过（4,557 项，10 跳过，0 失败，0 错误）。同一提交首次运行有一项启动重试 ID 断言失败，第二次运行通过。 [分支 CI 报告](https://github.com/wudahua/MCP_CREO_MechDog/actions/runs/45980797321/attempts/2)
