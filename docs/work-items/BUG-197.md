# BUG-197 包围盒口径与返回码、compact 摘要、圆角/倒角示例及健康状态拆分

分类：**已有修复但待验收**。缺陷，P2，目标版本 0.48.0。

来源为 [0.47.0 反馈](../validation/feedback-0.47.0-0.47.1-2026-11-26/SOURCE_MANIFEST.json) `v0470-legacy-snapshot-visibility.md` §3、§4.1–4.4。

## 范围

- `native/solid_bounds.h` 与 `src/creo_mechdog/server.py`（`creo_inspect_model`）：`bounding_box_status` 新增 `basis="tessellated_solid_union"`（区分所有实体按装配/零件几何面片细分并集口径与 Creo BodyBox / 点云紧包络口径），并在实测成功或报错时填入真实 `query_code`（`0` 或原生 `ProError` 码，不再恒为 `null`）；`creo_inspect_model` 文档补齐包围盒口径差异说明。
- `src/creo_mechdog/bridge.py` (`compact_job`) 与 `creo_get_job`：当存在 `inspection_summary` 且 `native["inspection"]` 尚无有效巡检时，同步填充 `result.inspection = inspection_summary`，并更新 `creo_get_job.sections` 参数描述示例为 `["operations", "inspection_summary", "preview"]`。
- `src/creo_mechdog/server.py`（`creo_round` / `creo_chamfer`）：在 `references` 字段描述中补充带 `'tolerance_mm':0.5` 与 `'full_circle':true` 的完整可复制示例。
- `src/creo_mechdog/session_health.py`（`snapshot`）与 `server.py`（`creo_session_status`）：保持既有顶层 `status`/`reason` 向后兼容，新增独立的 `connection_health`（反映当次探针/最近连接状态）与 `save_verification_health`（反映最近保存重载校验状态），并在 `creo_session_status` 按需刷新探针证据，避免把“600 s 无新保存”误读为“连接不可用”。

## 验收

- 单元测试（`tests/unit/test_feedback0470_snapshot_and_health.py::NativeFeedbackContractsTest`）：覆盖 `solid_bounds.h` `basis`/`query_code`、`compact_job` 摘要回填与 `sections=["inspection_summary"]`、工具 schema/文档描述以及 `session_health` 双子块拆分与 `creo_session_status` 刷新。
- 本机 Windows x64 / Python 3.12.10 / Creo 10.0.0.0（`release_numeric=42`）MCP stdio 实机验收（拉伸作业 `9b5c6fef6eaa4c88a3cc1e0737104d60`，模型 `51894e20c45d417da266764d1370289f`）：确认 `bounding_box_status.state == "measured"`、`basis == "tessellated_solid_union"`、`query_code == 0`；`creo_get_job(compact)` 填充 `result.inspection.total_surface_area_mm2`，`sections=["inspection_summary"]` 返回对应摘要；`creo_session_status` 返回 `connected=true`、`session_health.connection_health.status == "connected"` 与独立 `save_verification_health`（`status="no_failure_observed"`、`reason="recent_verified_save"`）。
