# BUG-205 Creo 10 曲面放样可用路径与必败路由前置拒绝

分类：**已有修复但待验收**。缺陷，P1，目标版本 `0.50.0`。基线为 v0.49.0 发布后回填提交 `949c7f6b`（衔接 `BUG-120` / `BUG-135`）。

来源：[0.48.3 反馈原件](../validation/feedback-0.48.3-2026-11-28/originals/weld-and-loft.md)（§2）与 [recovery-and-modeling.md](../validation/feedback-0.48.3-2026-11-28/originals/recovery-and-modeling.md)（P3）。

## 范围

- 在 `capabilities.require_kernel_completion` 对 Creo 10（`release_numeric == 42`）且未证实 `kernel_completion == "supported"` 的 `surface_loft` `creation_route="element_tree"` 请求（含 `accept_unverified_completion=true`）于提交前直接拒绝，明确指引在确认回调 `readiness="ready"` 后使用 `creation_route="resident_panel"`。
- 强化 `creo_capabilities` compact 口径下 `surface_loft` 的 `runtime_ready=false` 与 `runtime_admission` 提示，同步更新 `creo_surface_loft` 文档；保持 `native/surface_loft.cpp` 在零几何产出时回滚。

## 验收

- **实机验证（2026-11-28 Creo 10.0.0.0）**：两段 10 mm 平行线（Z=0 / Z=10）测试 `creation_route="element_tree"`，`accept_unverified_completion=false` 与 `accept_unverified_completion=true` 均在建作业前被直接拒绝（`No native job was queued`，引导 `creation_route='resident_panel'`）；`creo_capabilities(detail="compact")` 明确披露 `element_tree_status="known_release_extract_unsupported"` 与 `runtime_ready=false`。
- 单测：`tests/unit/test_surface_loft_kernel_admission.py`、`tests/unit/test_v0500_feedback_0483.py::Bug205Creo10SurfaceLoftTests` 通过。
- 未测范围：隔离执行桌面无法交互启动 Creo 回调，本版 `resident_panel` 同算例 100.0 mm² 新增曲面实机验收（在桌面启动回调后复验）、Creo 9 / 12.4 与 WorkBuddy 黑盒单列待验。
