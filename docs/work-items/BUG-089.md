# BUG-089：种子清单版本与发布工具不一致

类型：缺陷；优先级：P1；状态：已修复（0.8.2 交付）；目标版本：0.8.2 PATCH。

来源：0.8.1 发布后核对；关联 [0.8.1 发布记录](../validation/RELEASE-0.8.1.md)。

## 现象与根因

已确认 0.8.1 的 `version.py` 为 `0.8.1`，两份种子清单仍声明 `0.8.0`。直接运行文档中的 `tools/package_seeds.py --output` 因版本断言 exit 1。0.8.1 种子附件通过进程内修改版本构建，内部仍声明 0.8.0；`tools/test_installation_loft.py` 的安装版本核对在真实 0.8.1 安装上会失败。根因是发版时遗漏更新清单版本，并缺少对仓库实物的回归测试。

## 范围与验收

0.8.2 只同步版本及两份清单，保留种子列表、每个种子哈希和公开工具 94 个；补充离线回归测试。直接调用未修改的种子打包命令两次，哈希必须一致；回填 `seeds.py` 摘要并再构建核对。两次源码打包应一致，包含两份清单和反馈归档，禁入路径为零。`tools/dev_check.py` 必须成功、单元失败和错误均为零。禁止 Creo 和 WorkBuddy；无原生改动，不重编。证据见 [0.8.2 发布记录](../validation/RELEASE-0.8.2.md)。
