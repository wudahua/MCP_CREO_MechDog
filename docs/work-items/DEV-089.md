# DEV-089：安装文档补编译工具链实物预检与 Creo 13.4 编译层状态

## 当前摘要（2026-11-13）

分类：**已完成**。类型：工程整理。优先级：P2。目标版本：0.24.1。

来源：报告 P-01、P-02、P-03、P-12、P-13、P-14 与第 11 节建议 3。

## 问题或目标

报告环境暴露三处文档缺口：

1. `vswhere` 能列出 VS Build Tools 实例、`setup.ps1` 的文件检查也通过，但 `cl.exe`、`windows.h`、`kernel32.lib` 全缺，直到编译阶段才以 exit 4 暴露；INSTALL.md 没有把「三件实物检查」列为独立预检项。
2. `vcvars64.bat` 退出 0 但 `INCLUDE`/`LIB` 缺 UCRT 与 UM 路径（`reg.exe` 被宿主拦截）时，只能从 `build.log` 与 `compiler_preflight.py` 反推；文档缺少对应的本机包装脚本做法。
3. Creo 13.4.0.0（`release_numeric=45`）用 13.4 SDK 一次编译通过、常量表正常，但兼容矩阵仍只记 Creo 10/12。

## 范围

包含：`docs/INSTALL.md` 新增「编译工具链实物预检」小节（三条 `Test-Path`、`vs_installer.exe modify --quiet` 无输出不等于卡死、`-VcVars64` 包装脚本与 SDK 升级后需同步修改）；自动启动章节补 `creo_startup_args` 无图形示例、需重启服务、无图形建模已验证范围；配置表补 `creo_startup_args` 与 `creo_worker_launch`；常见问题补 `-4`/`worker_exit_code=20`、`-38` 模态框、冷启动等待、节点锁定许可下 `lmutil lmstat`/`ptcstatus.bat` 的 `-13,66` 不适用。`docs/COMPATIBILITY.md` 新增 Creo 13.4 行，只记编译层结果与未测范围。

不包含：不改 `setup.ps1` 检查流程；不新增 CI；不宣称 Creo 13 已支持；不把 PTC SDK 文件或许可数据写入仓库。
