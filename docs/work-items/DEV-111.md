# DEV-111 台账去重与活跃文档链接检查接入 CI

分类：**开发中**。P2。

`docs/BACKLOG.md` 页首与文末 `## 近期动态` 存在大段逐字重复动态，且活跃非冻结文档的本地文件链接与 `#锚点` 尚无自动化 CI 门禁。

范围与验收：
- 整理 `docs/BACKLOG.md`：每条动态在 `## 近期动态` 保留一份完整记录，页首仅保留最新摘要与跳转链接，保留全部已有章节与显式 `<a id="...">` 锚点，保持 `docs/validation/` 原件逐字节不变。
- 新增 `src/creo_mechdog/doc_links.py` 与 `tools/check_doc_links.py`，按 DEV-106 规则动态发现活跃非冻结 Markdown（`README.md`、`AGENTS.md` 与排除 `docs/archive/`、`docs/validation/`、`docs/release-notes/` 的 `docs/**/*.md`），校验本地相对路径与 `.md#锚点`，并接入 `.github/workflows/checks.yml`。
- `tests/unit/test_doc_links.py` 覆盖当前仓库通过、坏文件路径失败、坏 `#锚点` 失败、动态发现与隔离 CLI 调用。
