# BUG-201 能力回执 readiness 冲突、stderr 非 UTF-8 与诊断提示完善

分类：**已有修复但待验收**。缺陷，P2，目标版本 0.49.0。

来源为 [0.47.1 反馈](../validation/feedback-0.47.1-0.48.3-2026-11-27/SOURCE_MANIFEST.json) `v0471-runner-disconnect-panel-lock.md` §5 建议、§6.3–§6.6 建议、§7–§10（问题 G、H、J 及矩形/三点面/快照提示）。

## 范围

- `src/creo_mechdog/server.py` & `src/creo_mechdog/blend_callback.py` & `src/creo_mechdog/capabilities.py`：
  - `creo_capabilities` 中的 `direct_blend_callback` 与 `families.loft` / `families.surface_loft` 统一源自同一次 `bridge.callback_admission_status(artifacts)` 观测，消除同一回执内 `readiness="unknown"` 与 `"ready"` 矛盾；补充 `runtime_admission=null` 与 Start 后期望状态（`readiness="ready"`, `reason="live_identity_verified"`）说明。
  - `creo_callback_status` 在启动协调器运行中返回 `readiness="unknown"`, `reason="startup_in_progress"` 时附带 `startup_in_progress=True`、`readiness_phase="starting"` 与 `next_action`，消除状态歧义。
  - 服务端入口配置 `sys.stderr.reconfigure(encoding="utf-8", errors="replace")` 并显式绑定 logging stderr 流，防止非 UTF-8 字节导致 Python `mcp` 客户端读线程抛出 `UnicodeDecodeError`。
- `src/creo_mechdog/model_queries.py`、`src/creo_mechdog/schema.py`：
  - `legacy_snapshot` 状态下 `qualify_bounding_box` 补充 `refresh_hint`，`frames_note` 说明 tessellated 内缩误差方向。
  - `Rectangle` 误传 `corner1`/`corner2` 时提示使用 `min`/`max`；`through_points` 缺标签报错明确说明需为单点 `datum_points` 特征。
