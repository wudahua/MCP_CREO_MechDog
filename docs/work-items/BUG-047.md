# BUG-047：钣金折边 flip 未表现为可控方向变化

日期：2026-10-16。类型：缺陷。优先级：P1。状态：**根因已定并修复，实机两方向均通过（2026-10-29 第六轮）**——`flip` 原先写 `PRO_E_SMT_FLANGE_TRAJ_CRV_NORM`，两值几何完全相同；改写到 `PRO_E_SMT_FLANGE_SEC_FLIP` 后默认向外、`flip=true` 反向，`tools/test_flange_direction.py --live` 两例 `passed=true`。剩余未测：−X/−Y/+Y 边与第二道壁顶内/外缘的方向、`flip` 对多道连折的影响。目标版本：未排期。

来源：[0.3.1 钣金配电箱报告](../validation/feedback-2026-10-16/2026-10-16_CREO_0.3.1_钣金工具链增料失效与折边方向不可控等10项缺陷.md) S2；[补录](../validation/FEEDBACK-2026-10-16.md)。关联 FEAT-008、FEAT-014。

底板下缘 z=0、h80、flip=false 向 +Z；上缘 z=1、h80、false 向 -Z，上缘 h79、true 据报仍向 -Z（jobs `cb07084422874caabfa030cbb485e490` / `a4ca1713bf2e4cb39cf3c860056906a7`）。壁顶内/外缘再折边均向外，x91.5→111.5（`cb5b16b3a1da41ea915f15153126814e` / `0268e5da99c847dd91321442ca28b560`）。

需核实 flip 的公开语义是弯折方向还是材料侧，并补同边、同高、同半径、仅 flip 变化的对照；原实验同时改 h80→79，不能据此确认参数被忽略。边 ID 随模型变化，复现须 inspection 获取真实边。

范围与验收：第一道上/下缘及第二道壁顶内/外缘，独立工具/计划。声明可控的方向或材料侧须与几何一致，明确参考边/驱动面/正负方向，必要时回显方向与 bbox；向内 20 mm 的合法正例不能默认为向外。原生折边、半径/角度/高度、体积和保存重载 true、revision 正确；无效边/角部冲突拒绝后恢复可用。四壁释放能力另归 FEAT-014，不用该限制掩盖独立 flip 问题。

后续使用 Windows x64 / 本机 Creo 12.4 / 匹配 SDK、适用检查与折边方向原生回归；来源具体 Creo/OS/构建无法确认。本次仅登记。

## 2026-10-29 第六轮：根因定位、改为截面侧、两方向实机通过

- **根因**：方向开关接错了元素。`flip` 写的是 `PRO_E_SMT_FLANGE_TRAJ_CRV_NORM`（22:06 对照中 `false`→1 与 `true`→−1 的 bbox、体积、方向完全相同，说明它不改变折弯侧；`ProSmtFlangeWall.h` 对该元素只列 `PRO_B_TRUE/PRO_B_FALSE`）。
- **修复**：`generic_sheetmetal_flange` 保持 `PRO_E_SMT_FLANGE_TRAJ_CRV_NORM = NO_FLIP`（与库存 `UgSmtFlgWallCreate.c` 一致），把 `flip` 改写到 `PRO_E_SMT_FLANGE_SEC_FLIP`：`flip=false` → `PRO_B_TRUE`（从依附面法向向外，默认），`flip=true` → `PRO_B_FALSE`（材料侧）。别名记录新增 `bend_side`/`sec_flip_element`/`flip_input` 回显。
- **2×2 实测**（同边、h80/R2.54/Y0.5）：+X 顶边 `SEC_FLIP=FALSE`→down（z `[-79.5,0.5]`）、`TRUE`→up（z `[-0.5,79.5]`）；+X 底边 `FALSE`→up、`TRUE`→down。侧向相对依附面，不是全局坐标轴，因此"向外"对任意一条边都成立。
- **契约**：默认方向 = 从选中面法向向外；`flip=true` = 反向（材料侧）。驱动 oracle 同步改为"|z 增长| ≥ 0.9×height 且方向等于该例显式期望"。
- **实机**：`build/flange_direction/20261029T222510_9cebd5e1/report.json`（SHA256 `9464933e…`），`passed=true`；`angle90_outward` up、`angle90_inward` down，均 rev 2、`saved_file_reloaded_and_verified=true`、体积增量 18 025.29 mm³。机理解析证据见 `build/flange_side_probe/`。
- **仍未覆盖**：−X/−Y/+Y 边、第二道壁顶内/外缘的方向；`flip` 在一串连折中的稳定性；失败负例（无效边）回滚后再次合法折边。这些留待四壁闭环时补。
