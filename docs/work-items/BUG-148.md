# BUG-148 多开放轮廓曲面拉伸失败时缺少对应处理指引

分类：**已有修复但待验收**（0.35.6 交付修复）

类型：缺陷。优先级：P1。目标版本：未排期。

Creo 10 报告的两个开放轮廓同时拉伸返回 -1，逐轮廓拉伸则各得 288000 mm²。离线按可信 native 截面计数补错误提示，避免把单开放轮廓当成不支持；当前 Creo 10 实测对照单轮廓、两轮廓、闭合截面及回滚后再确定原生可用性，关联 BUG-049。

来源：[本批反馈计划](../archive/development/0.35.0-FEEDBACK-PLAN-2026-11-21.md)。

已实现失败提示并以 Creo 10 SDK/MSVC x64 编译。C++ 夹具覆盖两个开放轮廓、单开放轮廓、闭合轮廓和实体拉伸。按轮廓拆分用于后续模型验证，单次拉伸多开放轮廓仍需实测。

## 实机（2026-11-21，本机 Creo 10.0.0.0，`toolkit_code=0`）

同一内核上跑三组曲面拉伸，全部经 `creo_execute_plan` 提交，作业读取 `saved_reloaded` 快照：

| 用例 | 结果 |
| --- | --- |
| 两张开放直线、一次曲面拉伸 | `failed`、`stage=execute_extrude`；消息为 `ProFeatureWithoptionsCreate=-1`，并给出 `Detected native section: 0 closed contour(s), 2 contour(s), 2 entity(ies), 4 open end(s)`、`Max open endpoint gap 10 mm`、`The section contains multiple open contours. Try one sketch and surface extrude per open contour.` 与 `Sketch: 'two_open'` |
| 单张开放直线、一次曲面拉伸 | `succeeded`、`stage=verified`，`has_solid=false`、`quilts=1`，`inspection_source=saved_reloaded`。即单开放轮廓在单特征内可曲面拉伸，不能按“多轮廓不支持”一概而论 |
| 闭合矩形对照 | `succeeded`、`stage=verified`，同样 `quilts=1` |

结论：报告里的 -1 是“一次拉伸里放了多个开放轮廓”，不是“开放轮廓本身不支持”。两开放轮廓仍保留 -1 与拆分指引，未尝试在单特征内强行合并。
