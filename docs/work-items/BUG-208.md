# BUG-208 boolean_bodies 支持初始负实体 ID -5778 与空实体拒绝

分类：**已有修复但待验收**。缺陷，P1，目标版本 `0.50.0`。基线为 v0.49.0 发布后回填提交 `949c7f6b`（衔接 `DEV-075` / `FEAT-014`）。

来源：[0.48.3 反馈原件](../validation/feedback-0.48.3-2026-11-28/originals/recovery-and-modeling.md)（P8）。

## 范围

- `schema.py` `BooleanOp` 与 `extrude.scope` 对齐，放行 Creo 初始实体 ID `-5778`（仍拒绝其他负数 ID）。
- `native/surfaces.cpp` `generic_boolean` 先遍历 `ProSolidBodiesCollect` 校验所有目标与工具体存在且为 `PRO_BODY_STATE_ACTIVE`（拒绝空实体/无材料体，并保留钣金限制），再以精确 `selection(id, PRO_BODY)` 构造布尔并回报体数与体积前后值。

## 验收

- **实机验证（2026-11-28 Creo 10.0.0.0）**：
  - 活动 `-5778` + 正 ID 活动实体（在带 `-5778` 实体上追加 `id=135` 凸台）：`boolean_bodies` 并集成功（`feature_id=161`），体积 `5750.0 → 4625.0 mm³`，终态 `objects=1 / active=1 / with_material=1`，`saved_file_reloaded_and_verified=true`。
  - `-5778` 空实体拒绝：两正实体建模零件上对 `-5778` 提交并集，按 `BOOLEAN_BODY_NOT_FOUND` 拒绝且几何无变更。
  - 正 ID + 正 ID 活动实体并集对照（两 `8000 mm³` 相交方块）：并集成功，`volume_mm3=12000.0`，1 实体，`saved_file_reloaded_and_verified=true`。
- 单测：`tests/unit/test_v0500_feedback_0483.py::Bug208BooleanBodyIdTests` 与 `tests/unit/test_operation_validation_messages.py` 通过。
- 未测范围：Creo 9 / 12.4 与外部 WorkBuddy 黑盒验收。
