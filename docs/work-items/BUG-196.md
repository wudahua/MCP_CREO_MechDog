# BUG-196 历史模型快照看不到 0.41.0+ 新验收字段与只读回写

分类：**已有修复但待验收**。缺陷，P1，目标版本 0.48.0。

来源为 [0.47.0 反馈](../validation/feedback-0.47.0-0.47.1-2026-11-26/SOURCE_MANIFEST.json) `v0470-legacy-snapshot-visibility.md` §1。0.39.0 等早期版本保存的受管模型快照中不包含 0.41.0 新增的 `total_surface_area_mm2`、`bounding_box_mm`、`merged_counts` 与逐面 `area_mm2`；`creo_refresh_model` 只写 job 的 `last_live_inspection`，导致 `creo_inspect_model` 始终读回旧快照，迫使验收方必须再执行 `save_model` 升 revision 或改文件字节才能看到面积与包围盒。

## 范围

- `src/creo_mechdog/server.py`（`creo_refresh_model` / `creo_inspect_model`）与 `src/creo_mechdog/generic_bridge.py`（`submit` / `run_generic_job`）：`creo_refresh_model(model_id, write_back_snapshot=False)` 新增可选只读回写开关 `write_back_snapshot`；`submit` 校验仅允许用于现有模型上的空操作只读刷新。
- `write_back_snapshot=True` 且磁盘 `part_sha256` 未变时，把实测 `inspection`/`inspection_ref`/`inspection_summary` 回写到模型控制记录快照，并标明 `snapshot.source="refresh_verified"` 与 `snapshot.refreshed_at`，**保持 `revision`、`part_file`、`part_sha256`、`updated_at` 与模型文件字节不变**；`compact_sections.py` 将 `snapshot_write_back` 列入 `RESULT_KEYS` 与 `PROTECTED_RESULT_KEYS`；SHA256 不一致时拒绝覆盖并输出 `reason="part_sha256_mismatch_or_missing"`。
- `src/creo_mechdog/model_queries.py`（`model_summary`）：对仍缺 `total_surface_area_mm2` / `bounding_box_mm` / `merged_counts` / 内联 `surfaces[].area_mm2` 的已保存实体模型快照输出 `snapshot.stale_fields` 与 `snapshot.refresh_hint`。

## 验收

- 单元测试（`tests/unit/test_feedback0470_snapshot_and_health.py::LegacySnapshotBackfillTest`）：覆盖 `model_summary` 对旧快照输出 `stale_fields`/`refresh_hint`、`write_back_snapshot` 准入拦截、只读回写保持 `revision`/`part_sha256`/`updated_at` 不变、`part_sha256` 不一致拒绝覆盖与 `compact_sections` 保护。
- 本机 Windows x64 / Python 3.12.10 / Creo 10.0.0.0（`release_numeric=42`）MCP stdio 实机验收（模型 `51894e20c45d417da266764d1370289f`，`revision=3`，`part_sha256=4b4aba80b13543c476142bd3e2153d8d5482b4cac5d15a2c35a9997c00b7e3d6`）：将临时模型快照手工退化为 pre-0.41.0 结构后，`creo_inspect_model(compact)` 报告 `stale_fields=["total_surface_area_mm2", "bounding_box_mm", "surfaces[].area_mm2"]` 与 `refresh_hint`；调用 `creo_refresh_model(write_back_snapshot=True)`（作业 `f02aa955b1154ff6955d6a97249083f2`）返回 `snapshot_write_back.applied=true`；随后 `creo_inspect_model(compact)` 与 `detail="full", section="surfaces"` 读出 `snapshot.source="refresh_verified"`、`total_surface_area_mm2=904.7786842338605` 与 4 个面的 `area_mm2`（`201.0619`/`201.0619`/`251.3274`/`251.3274`），`revision` 保持 `3` 且 `part_sha256` 未变。
- 未测范围：Creo 9 / Creo 12.4 实机与外部 WorkBuddy 黑盒复测（0.39.0 原历史模型待外部使用方在工作区直接复测）。
