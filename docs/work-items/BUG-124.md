## 已交付（离线，2026-11-13）

- 入口契约：`schema.py` 新增 `ImportGeometryOp`（`op/file/profile/format/file_sha256/profile_sha256`）并加入 `Operation` 联合体；`file`/`profile` 解析为绝对路径、必须存在，扩展名必须与 `format` 一致（step→`.stp/.step`，iges→`.igs/.iges`），未给摘要时按磁盘内容补 `sha256`，给了摘要但与磁盘不符即拒绝。`profile` **可选**：头文件写明「Once a profile is set, it remains valid for the entire session」，所以默认不传（`profile` 传 NULL，用 Creo 自己的导入设置），只有调用方坚持时才显式给文件；回执的 `profile_source`（`explicit`/`creo_default`）说明这一次走的是哪条。`profile_sha256` 只能与 `profile` 同时出现。

- 原生（`native/import_geometry.cpp`，由 `generic.cpp` 包含）：新建模型分支不再复制零件模板，改为 `ProIntfimportModelWithOptionsMdlnameCreate(file, profile-or-NULL, STEP/IGES, PRO_MDL_UNUSED, PRO_IMPORTREP_MASTER, name, NULL, NULL, &created)`；执行前重算输入文件的 SHA256（`profile` 只在给出时校验；不符即 `IMPORT_GEOMETRY_INPUT_CHANGED`），失败码原样进错误信息与回执（`create_code`/`create_code_name`，含 `PRO_TK_NO_LICENSE=-40`）。回执另报 `created_model_name`、`model_type`、`units`、`feature_count`、`quilt_count/quilt_ids`、`quilt_closure`、`area_mm2`/`area_status`（未测到就是 null + 原因，不填 0）；操作分派只重放该回执，重复导入或追加到既有模型在原生侧再次拒绝。

- 纯曲面（非实体）STEP 未实机验证：本次两个样本都是实体件导出，`quilt_count=1/6`、面积可测，但没有证明薄面/开放面组的导入表现。
- 导入结果是"导入特征 + 原生面组"还是可直接参与 `quilt_merge`/`mirror`，未验证。
- 单位：导入的 STEP/IGES 若为英寸，`generic.cpp` 既有的毫米校验会在导入后拒绝并回滚；导入前不做单位换算，回执里的 `units` 只是读数。

- 实机验收口径：STEP 与 IGES 各一次导入 + 保存重载已达标并据此删除门禁（见上）；仍缺纯曲面样本与 Creo 10（`release_numeric=42`）复测，二者任一失败都应把 `import_geometry` 放回 `UNAVAILABLE_OPERATIONS`。
