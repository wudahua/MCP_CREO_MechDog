# BUG-128：Toolkit 错误码缺少可操作诊断提示

## 当前摘要（2026-11-13）

分类：**已完成**。类型：缺陷。优先级：P2。目标版本：0.24.1。

来源：报告 P-06 与第 11 节建议 4。与 FEAT-006（统一错误码与字段位置）方向一致；本条只加提示，不改字段结构与错误码含义。

## 问题或目标

报告环境里 `-38` 只给出笼统的「忙」，实际原因是 `xtop.exe` 窗口标题被 `NVIDIA OpenGL Driver` 模态错误框占用，驱动对话框阻塞了 Creo 消息循环。同类误判风险：

- `-4`（`PRO_TK_BAD_CONTEXT`）容易被读成权限或许可问题，实际是 worker 没有 Toolkit 上下文（[BUG-127](BUG-127.md)）。
- `worker_exit_code=20` 只是探针失败的退出约定，不是 Creo 错误码。

## 范围

包含：`bridge.session_status()` 返回值新增 `toolkit_hint`，为 `0`、`-4`、`-8`、`-36`、`-38` 与未知码给出固定提示，`worker_exit_code` 非 0 时补「退出码 20 是探针约定」；`creo_startup` 的 `launch_failed` 消息引用该提示；文本不含本机路径、许可值或命令行。

不包含：不改 `toolkit_code`、`connection_state` 的既有取值；不改 C++ 返回码；错误码到异常类型的重构留给 FEAT-006。

## 验收标准

| 环境 / 用例 | 命令或操作 | 可判断的预期结果 |
| --- | --- | --- |
| Windows / Python | `tests/unit/test_toolkit_hints.py` | 各码提示非空；`-4` 明确「不是许可或版本问题」；`-38` 明确指向模态对话框；未知码可用 |
| Creo 12.4 本机 | 无会话探针 | 返回的 `toolkit_hint` 与 `-4` 现象一致，无路径泄漏 |

## 实现与证据

`bridge.py`（`TOOLKIT_HINTS`、`toolkit_hint`）、`creo_startup.py`（`launch_failed` 文案）。真实探针输出见[本次证据](../validation/STARTUP-HEADLESS-2026-11-13.md#bug-128)；`-38` 与真实模态框的对照未做。
