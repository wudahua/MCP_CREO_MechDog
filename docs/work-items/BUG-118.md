# BUG-118：compact 预算裁剪先剥掉曲面放样回执的测量值，只剩 `detail_truncated`

## 当前摘要（2026-11-11）

分类：**已修复并实机验收**（随 0.21.1 发布）。类型：缺陷（回执可用性）。优先级：P1（compact 是轮询主视图）。

发现场景：0.21.0 发布后复跑 `tools/test_surface_loft_guides.py` 的「3 截面 + 2 导线」用例（FEAT-065/M2）。作业本身成功（`section_count=3`、面积 1599.9999999999995 mm²、单张开放 quilt、保存重载通过），但 **compact 视图里整条 `surface_loft` 记录只剩 `detail_truncated`**，`surface_area_mm2`/`guide_count`/`quilt_count`/`quilt_closed_native` 全为缺失。

## 现象（2026-11-11，Creo 12.4.0.0）

作业 `6510998c…`（3 截面 + 2 导线，6 个 op）同一份 manifest 的两种视图：

- `detail=compact`：`operations` 6 条，`surface_loft` 记录 `detail_truncated=true`，测量字段全部缺失。
- `detail=full`（分页）：`section_count=3`、`guide_count=2`、`quilt_count=1`、`quilt_closed_native="open"`、`surface_area_mm2=1599.9999999999995`、`has_solid=false`。

同为 `surface_loft` 的 2 截面作业（`fe3ca793…`、`e2646c3a…`）compact 未超预算，测量值正常，所以这条缺陷只在「op 多 / 单记录大」时才暴露。

## 根因

`src/creo_mechdog/operation_results.py::enforce_compact_budget` 第 2 阶段从**最后一条记录倒序**剥可选字段，剥到只剩 `PROTECTED_OPERATION_KEYS` + `FAILED_EVIDENCE_KEYS`。曲面放样的测量字段不在保护集合里，而放样记录恰好是计划最后一条，于是第一条被剥的就是它；剥完刚好回到预算内，前面的草图记录全部保留——最该保留的记录被牺牲。

## 修复（0.21.1）

- 新增 `OUTCOME_OPERATION_KEYS`（`quilt_id`/`quilt_ids`/`quilt_count`/`quilt_closed_native`/`has_solid`/`surface_area_mm2`/`surface_area_status`/`section_count`/`section_curve_ids`/`guide_count`/`guide_curve_ids`/`piecewise_ruled`/`interpolation`/`volume_mm3`/`curve_id`/`length_mm`/`surface_id`），并入 `_status_core` 的保护集合。它们都是标量或几个整数，体积远小于被裁掉的大块，裁剪仍有意义。
- `enforce_compact_budget` 文档写明「测量标量不再被裁」；预算仍硬性生效，保护证据本身超预算时依旧走 `result_budget` 如实报告。
- 回归用例 `tests/unit/test_large_plan_result_budget.py::test_a_trimmed_surface_receipt_keeps_its_measurements`：构造超预算 manifest，断言放样记录 `detail_truncated=true` 且测量字段齐全。
- 实机回归：`tools/test_surface_loft_guides.py --live --confirm-session-usable` 的 3 截面用例由「回执为空导致 2 项 FAIL」变为全 PASS（`job 2a2ee086…`，`section_count=3`、`guide_count=2`、面积 1599.9999999999995 mm²、bbox 40.12/40.12 mm、保存重载 verified）。

## 未测范围

- 只验证了 `surface_loft` 的记录形态；其他同样不在保护集合内、又可能被整体剥掉的 op 类型未逐项核对。
- 预算边界本身未重新测量（仍为 `RESPONSE_BUDGET` 32 KiB）；保护标量后单条放样记录大约多出 200—400 字节，未做长计划下的极端预算压测。
