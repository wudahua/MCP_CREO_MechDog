# BUG-206 creo_new_loft_part 种子组合矩阵披露与 new_part_only 标注

分类：**已有修复但待验收**。缺陷，P2，目标版本 `0.50.0`。基线为 v0.49.0 发布后回填提交 `949c7f6b`（衔接 `BUG-154`）。

来源：[0.48.3 反馈原件](../validation/feedback-0.48.3-2026-11-28/originals/weld-and-loft.md)（§3）与 [recovery-and-modeling.md](../validation/feedback-0.48.3-2026-11-28/originals/recovery-and-modeling.md)（P4）。

## 范围

- `creo_list_seeds` 新增返回精确本机 `verified_combinations` / `available_combinations` 与 `missing_bundled_combinations`（明确列出 `5/straight` 缺失）及 `target_scope="new_part_only"`、`explicit_seed_section_range=[2, 20]`。
- 为 `creo_new_loft_part`、`callback_free_route`、`native/blend_create.cpp` `SEED_ROUTE_NOTE` 及 `BLEND_CALLBACK_SETUP_REQUIRED` 显式标明 `new_part_only`（不可向已有零件追加），保留显式兼容种子入口。

## 验收

- **实机验证（2026-11-28 Creo 10.0.0.0）**：`creo_list_seeds` 返回 9 组精确组合与 `missing_bundled_combinations=[{"section_count": 5, "interpolation": "straight"}]`、`target_scope="new_part_only"`；`creo_new_loft_part` 拒绝 `5/straight` 并给出精确可用组合与 `creo_install_seed_library` / 显式种子提示；`2/straight` 新建放样件（`5b2f628c3dcb404ab32d586131144424`）体积 `3500.0 mm³` 且 `saved_file_reloaded_and_verified=true`。
- 单测：`tests/unit/test_v0500_feedback_0483.py::Bug206SeedMatrixTests`、`tests/unit/test_seed_listing.py`、`tests/unit/test_seed_preflight.py` 全部通过。
- 未测范围：Creo 9 / 12.4 与外部 WorkBuddy 黑盒验收。
