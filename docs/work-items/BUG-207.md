# BUG-207 草图 auto 混合圆弧回退顺序与 coordinates 椭圆支持

分类：**已有修复但待验收**。缺陷，P1，目标版本 `0.50.0`。基线为 v0.49.0 发布后回填提交 `949c7f6b`（衔接 `BUG-194`）。

来源：[0.48.3 反馈原件](../validation/feedback-0.48.3-2026-11-28/originals/recovery-and-modeling.md)（P5、P6）。

## 范围

- 对混合圆弧轮廓修正 `profile_dimensioning_choice` 的 `selection_reason`（曲率实体标注为 `autodim_preferred_for_curved_entity`，仅对 `spline` 输出 `unsupported_coordinate_entity`）。
- 当 `dimensioning="auto"` 在无约束的坐标可支持轮廓上首次 `autodim` 求解/再生失败时，支持清晰回退至 `coordinates` 并保留 `fallback_from="autodim"`、`autodim_error` 与 RAII 不完整特征清理（不破坏 `autodim` 成功时对 `arc`/`b_spline` 的保护）。
- 在 `coordinates` 模式下补齐 `PRO_2D_ELLIPSE`（`PRO_TK_DIM_ELLIPSE_X_RADIUS` / `PRO_TK_DIM_ELLIPSE_Y_RADIUS` 与中心点位置）、`row["radii"]` 偏差快照与 Python `SketchOp` 校验。

## 验收

- **实机验证（2026-11-28 Creo 10.0.0.0）**：
  - 混合圆弧槽口在 `auto`（`selection_reason="autodim_preferred_for_curved_entity"`）、`coordinates` 与 `autodim` 下均创建并挤出成功，实测体积均为 `1392.6991 mm³`，`saved_file_reloaded_and_verified=true`。
  - 偏置椭圆（`center=[18, -12]`, `x_radius=24`, `y_radius=11`, `depth=8`）在 `dimensioning="coordinates"` 下实机通过：`SKETCH_SOLVE=0`、`SectionRegenerate=0`、`geometry_deviation.max_deviation_mm=0.0`（`origin_radii`），挤出体积 `6635.0333 mm³`（理论 `6635.0437 mm³`），`bbox.size=[48.0, 22.0, 8.0]`，`saved_file_reloaded_and_verified=true`。
  - `(0, -0.092)` R3 自动草图圆心回归：实测体积 `282.7433 mm³`（理论 `282.7433 mm³`），`bbox` 对齐 `(0, -0.092)`，`saved_file_reloaded_and_verified=true`。
- 单测：`tests/unit/test_v0500_feedback_0483.py::Bug207EllipseSchemaTests` 通过。
- 未测范围：Creo 9 / 12.4、真实外部失败曲线触发 `autodim→coordinates` 运行期回退实机原件及 WorkBuddy 黑盒验收。
