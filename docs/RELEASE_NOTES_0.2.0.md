# MCP_CREO_MechDog 0.2.0 — MIT 源码安装版

用于连接本地 Creo Parametric 10 的通用参数化建模 MCP，提供 31 个工具。AI 可组合草图及顺序特征，从零创建可编辑、保留原生特征树的零件。

主要能力：

- 草图：直线、中心线、圆、圆弧、矩形、多段线、样条、椭圆，以及尺寸和约束接口。
- 拉伸及旋转：增材、切除、曲面、薄壁、对称深度或角度等分支。
- 原生直孔、恒定半径圆角、等距倒角、抽壳、基准面、基准轴、一方向尺寸阵列。
- 修改模型尺寸、草图尺寸、参数及简单算术关系式。
- 查询特征树和拓扑，创建高级 Toolkit Element Tree 特征。
- 保存原生 PRT，导出 STEP、IGES、STL、JPEG；修改任务包含保存及重载验证。
- 版本检查和失败恢复，串行执行原生任务。

安装方式：下载并解压源码，在自己的 Windows x64 电脑执行 `setup.ps1`。需要 Python 3.12+ x64、Creo 10 及匹配 Toolkit SDK、MSVC x64 构建工具、可用的 PTC 许可，以及支持本地 stdio MCP 的 AI 客户端。详细步骤见 `docs/INSTALL.md`。

开发环境已完成 41 个成功原生任务和 11 项输入验证测试，公开摘要见 `docs/validation.json`。当前实测版本为 Creo 10.0.0.0；其他维护版本及环境需要使用者验证。提供接口不代表每种几何、约束或参数组合都已验证。

当前范围为 MCP 创建并登记的零件。镜像、扫掠、混合/放样、拔模、筋、标准螺纹/沉头/沉孔、钣金、装配和工程图尚未封装高层工具。不能保证所有文字描述自动建模成功。
