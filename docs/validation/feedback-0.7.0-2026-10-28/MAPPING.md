## 输入缺口与共同边界

在仓库与指定下载目录未发现 `gear10.json`、`sketch_entities.json`、`sketchgen.py`、30 段截面原请求、新旧星形 PRT、失败作业的 request/job/native_result JSON 或原始预览图。四份 Markdown 中的 job/model ID 是定位线索，不是这些附件。后续取得原件须另记来源与哈希；替代夹具明确标记 replacement，不宣称原构型重放。

共享契约：弧 `dir` 缺省仍为 CCW；Toolkit 单通道忙时立即拒绝，不排队或重提；已受理作业只轮询 `creo_get_job`。回显实际回转轴、单位或几何时，查询不到须给未知/null 与原码，不能回声请求值。长度毫米、角度度；preview 文件缺失归 BUG-088/T08A，文件存在但内容或视角失真归 BUG-066/T08C。工作卡仅登记范围；本次无原生、单元、构建或 WorkBuddy 验收。
