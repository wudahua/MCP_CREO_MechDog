## 一、第五节 水下艏部：球鼻艏形隆起（第 77~91 行）

> 在艏部下方制作一个沿 X 方向伸展、前端圆尖、横向圆鼓的球鼻艏形体，中心高度约 Z=-5.6 米。它不是整艘船前端再加一个球，也不是在 Z=0 甲板上放置圆柱。
>
> 记录中的位置范围约：X=64.094736～78.098843 米，Z=-6.600046～-4.599998 米。一个半体位于 Y=-1.818679～0，另一个通过 Y=0 镜像得到。可用全宽约 3.6 米、高约 2 米、长约 14 米概括。
>
> 较细致的做法是在三个 X 截面制作截面轮廓，并配合纵向导线放样：
> 在 X=64.094736 米的后截面，曲线两端在 (X,0,-4.6) 和 (X,0,-6.6)，中间向 Y 负侧鼓出；横向控制值最大约 1.81 米，曲线实际鼓出幅度略小于控制点极值。
> 在 X=72.094736 米的中截面，同样由 Z=-4.6 连接至 -6.6，最大控制横向值约 1.41 米。
> 在 X=78.094736 米处收敛到尖点 (78.094736,0,-5.6)。
> 上方纵向导线先从 (64.094736,0,-4.6) 直行到 (72.094736,0,-4.6)，再弯至前尖点。
> 下方纵向导线从 (64.094736,0,-6.6) 直行到 (73.894736,0,-6.6)，再向上弯到前尖点。
> 中高 Z=-5.6 的侧向导线在后部 Y=-1.8，向前逐渐收敛到 Y=0。
> 附录 Sketch64、65、67、69、70、72 给出完整样条控制点和节点。制作半片曲面后封闭、缝合为实体，再镜像成左右对称的形状。和船体接触处可按软件能力合并，也允许为便于编辑保留为单独实体。
>
> **建议近似：如果软件不容易进行导线曲面放样，可用后截面长圆/椭圆、前尖点的多截面放样代替**；保持 X 范围、中心高度、全宽与高度，尤其保持横向鼓出及前尖端。

> ⚠️ 最后那句"建议近似"被本项目**明确禁用**。原因：3 条纵向导线是源模型的真实约束，去掉导线后曲面形状不可控，也无法与源模型比对。这条约束是任务背景，不是 MCP 的问题。

## 二、附录 B030（第 1084~1087 行）—— 本次唯一失败点

> **B030．Surface-Loft2：导线曲面放样。**
> 截面按艏尖点 Sketch69、X=72.094736 的 Sketch70、X=64.094736 的 Sketch72 排列；上、侧、下三条纵向导线分别来自 Sketch64、Sketch67 的样条、Sketch65。
> 草图/曲线组：Sketch69、Sketch70、Sketch72、Sketch64、Sketch65、Sketch67。

对 `creo_surface_loft` 的直接映射：

```
sections = [ Sketch69(收敛点), Sketch70, Sketch72 ]     ← 3 个，第一个是点
guides   = [ Sketch64(上), Sketch67(侧), Sketch65(下) ] ← 3 条
interpolation = "smooth"                                ← 3 截面以上必须 smooth
```

## 三、B030 之后的整条链（第 1089~1109 行）

> **B031．Surface-Plane1：平面封闭曲面。** 封闭球鼻艏半体的中心纵向侧面；曲线边界由球鼻艏上、下纵向轮廓组成。
>
> **B032．Surface-Plane2：平面封闭曲面。** 封闭球鼻艏半体的后截面，位于 X=64.094736。
>
> **B033．Surface-Knit1：曲面缝合。** 把球鼻艏半曲面和两片封闭平面缝合，形成封闭实体。
>
> **B034．Mirror4：关联镜像实体/曲面。** 镜像对象：Surface-Knit1；以纵向中心面 Y=0 镜像。原对象仍保留，产生另一半。源记录保留为独立几何对象。
>
> **B035．Fillet1：圆角。** 半径 1。定位边两端：(72.094736179, 0, -6.6) → (51.2, 2.1, -6.6)。
>
> **B036．Combine1：布尔合并。** 船体与其中一个球鼻艏半体作布尔并集；另一半的分体状态允许保留。

**这条链在 MCP 里全部有对应工具**（`surface_fill` / `quilt_merge` / `mirror` / `round` / `boolean_bodies`），且其中 `surface_fill`（平面数据面）已在 Creo 10 上实测可建。**唯一断点就是 B030 这一张曲面。**
