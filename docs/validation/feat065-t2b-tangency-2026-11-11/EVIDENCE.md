# FEAT-065 T2b：边界混合相切条件试值取证（2026-11-11）

环境：Windows x64，Creo 12.4.0.0 + 匹配 Toolkit SDK。用户当次确认授权实机测试，内容包括编译执行器、新建测试模型和试值实验；未结束或重启 Creo，未清锁，未做故障注入。

## 为什么用试值法

`Probbl.h` 只为 `PRO_E_BNBLN_TAN_COND_TYPE` 写了一个有效值 `TAN_COND_FREE`，而且这个宏没有可解析的定义，所以 SDK 文档没有给出「相切」对应的整数。原计划是用 Creo 界面手工建一个参照件，再读回它的特征树；用户不熟悉界面操作，因此改为在测试模型上逐个试候选值，用实测几何判断效果。

## 方法

- 几何：两张 40×10 mm 的竖直曲面带（拉伸曲面），间距 20 mm。用 `creo_measure_surface_group` 的 `open_edge_records` 按端点取两条顶边（edge 53、85），作为 `surface_loft` 的两个截面，不加导线。
- 判据一：补面的面积和包围盒。边界自由时，补面是 z=10 的 800 mm² 平面。
- 判据二：把一张曲面带和补面做 `quilt_merge` JOIN，再用 `creo_measure_surface_curvature`（faces=[0,1]）读接缝的 `g1_max_angle_deg`。
- 执行器：提交 `7b5c4ff` 的 `native/surface_loft.cpp` 加一个**临时实验钩子**，这个钩子没有提交。钩子读取环境变量 `MECHDOG_EXPERIMENT_TAN_COND`，把列出的截面边界标记为 `tangent`，并给出条件值 `v`、`TNC_BNDRY` 下标、`k=1`（保留内核默认面链）、拉伸系数（`s` 统一设置，或 `sN` 按下标单独设置），借此执行 T2a 的「映射已知」分支。试值驱动见 [m4_trial_driver.py.txt](m4_trial_driver.py.txt)。实验结束后，钩子被丢弃，`surface_loft.cpp` 恢复到实验前版本，再写入下文的实测映射。
- 23 组试验全部成功，每组都保存重载 verified。逐组数据见 [trials.json](trials.json)，里面有作业 ID、模型 ID、面积、包围盒和接缝角度。

## 结论与落地

- 相切：`TAN_COND_TYPE=2`，并且必须写 `PRO_E_BNBLN_STRETCH`，首截面 -1、末截面 +1。面链沿用内核默认（方法 1，引用边的相邻面），不重建。
- `TNC_BNDRY` 下标 0 = 首截面，1 = 末截面。导线边界（下标 2、3）没有测量。
- 曲率与法向没有找到有实测依据的值，继续拒绝；导线边界上的非自由条件同样拒绝。
- 映射写在 `native/surface_loft.cpp` 的 `SURFACE_LOFT_TAN_COND_TYPE_VALUES`、`SURFACE_LOFT_TNC_BOUNDARY_INDEX`、`SURFACE_LOFT_TANGENT_STRETCH`。最终代码的实机复核另由 `tools/test_surface_loft_continuity.py --live` 完成，结果记在 FEAT-065 工作卡。
