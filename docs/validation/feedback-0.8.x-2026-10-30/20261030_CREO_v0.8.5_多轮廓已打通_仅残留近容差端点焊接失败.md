# MCP_CREO_MechDog v0.8.5 验收报告

> 核心结论：**连续 3 轮（v0.7.0 / v0.7.2 / v0.8.2）阻塞的"同一草图多轮廓 ≤ 2"问题已解除。**
> v0.8.5 实测可在一个草图内成功构建 **10 个闭环**（单实体圆、多实体方、纯弧链三种形态全部通过）。
> 剩余唯一功能性阻塞是：**相邻实体的共享端点若只"接近"而未"精确重合"（间隙达到 1e-6 容差的 ~0.8 倍），Creo 原生截面不会焊接，草图仍被提交，失败被推迟到拉伸阶段（`ProFeatureWithoptionsCreate=-1`）。**

## 2. 验收方法

延续前几轮建立的**体积金标准**：每个用例的期望移除量由解析几何算出，与 MCP 回报的
`material_removed_mm3` 逐位比对。所有用例都在**新建的干净探针零件**上做，避免历史探针污染证据。

本轮额外引入了**三组 A/B 对照**，用来把"多轮廓数量限制"与"端点焊接"两个假设彻底分开：

| 对照 | 轮廓形态 | 端点重合方式 | 期望移除量（depth 10） |
|---|---|---|---|
| A | 10 个圆 r=3 | 单实体闭环，无端点问题 | 282.743338823×10 = **2827.433388** |
| B | 10 个 6×6 方形 | 多实体链，**字面值完全重合** | 360.0×10 = **3600** |
| C | 10 个 4 弧链闭环 | 多实体链，**构造保证 ~1e-12** | 185.299203×10 = **1852.992** |
| D | 原始 gear10（40 弧 / 10 槽） | 多实体链，**间隙最大 7.72e-7** | 184.980296×10 = **1849.802857** |
| D′ | 同上，仅做端点吸附 | 多实体链，**间隙 7.83e-13** | 同上 |

## 4. 残留问题汇总（按优先级）

### P1 — 近容差端点不焊接，失败被推迟到拉伸阶段（功能阻塞，唯一）

**现象**：相邻草图实体的共享端点距离接近但不超过 `tolerance_mm = 1e-6` 时，Creo 原生截面不把它们焊接成闭环。
草图仍然 `succeeded / committed`，失败推迟到 `creo_extrude`，表现为 `ProFeatureWithoptionsCreate=-1`。

**实测边界**（同一几何、同一版本、同一零件）：

| 端点间隙 | 原生截面 | 结果 |
|---|---|---|
| ≤ 9.19e-13 mm | 10 closed / 0 open | ✅ 通过 |
| ≈ 7.72e-7 mm（0.77×tol） | 2 closed / 14 contours / 24 open | ❌ 失败 |

**为什么这是真实风险而不是我的素材问题**：`gear10.json` 里的坐标只是保留了 6 位小数，这是
**任何从上游 CAD/脚本/自然语言规格导出的截面都会有的正常舍入**。用户无法预判自己的坐标会掉进
"0.5×tol ~ 1.0×tol"这个死亡区间。

**建议在 MCP 侧做（任选，按推荐度排序）**：

1. **端点吸附（最推荐）**：`creo_create_sketch` 在写入原生截面前，对距离 `< tolerance_mm` 的端点做一次
   weld/snap（合并为同一顶点）。用户侧的等价做法我已验证可行——把共享顶点取为两段弧名义端点的中点、
   弧心投影到弦的垂直平分线——但这属于要求用户掌握数值技巧，不应该由调用方承担。
2. **把 `near_tolerance` 升级为可操作诊断**：现在它只是 `profile.categories` 里的一个**计数**（失败时是 40/40，
   成功时是 0），没有任何后续动作。建议至少返回：
   - `max_endpoint_gap_mm`（最大端点间隙）
   - `near_tolerance_pairs`（哪两个实体的哪两端、间隙多少）
   - 在 sketch 结果里加 `warnings: [...]`，让调用方在**建草图时**就知道，而不是等到拉伸才炸。
3. **提供可调容差**：给 `creo_create_sketch` 加可选 `tolerance_mm`（默认 1e-6），或把默认值放宽到 1e-5。
   对 mm 单位零件，1e-5 通常仍然安全，但能把"7.7e-7 这种正常舍入"完全排除在死亡区间之外。
4. **失败时定位到实体**：`creo_extrude` 失败时，除了 `open_ends` 计数，建议列出**开放轮廓的成员实体名**，
   这样调用方能直接改对的那个点。

### P2 — `profile`（MCP 解析）与 `native_section`（Creo 实际）不一致，且不做交叉校验

同一份输入，MCP 报 `closed_contour_count = 10`，Creo 报 `closed_contours = 2`。
建议：当 `native_section` 可用时，若 `native_section.open_ends > 0` 或
`native_section.closed_contours != profile.closed_contour_count`，在 **sketch 结果里就给出 warning**，
而不是等 `ProFeatureWithoptionsCreate` 返回一个无法定位的 `-1`。

### P3 — `view_matrix_matches` 恒为 false；建零件时 preview 必失败

- 本轮所有 job（10+ 个）`preview.view_matrix_matches` **全部为 false**，无一例外。
- `creo_new_part` 的 job preview **必失败**：`failed_step = output_file`，`failed_code = -4`，
  `verification_error = FileNotFoundError`，`file_check.error_message = "The system cannot find the file specified."`。
  （建模 job 的 preview 本轮**全部 written**，相比 0.8.2 是明显改善。）

### P4 — 删除/抑制/恢复、拔模、倒圆角只存在于 `creo_execute_plan` 通道

工具描述显示 `creo_execute_plan` 支持 `feature_state`（delete / suppress / resume）与
`draft`、`round`、`chamfer` 等 op，但**没有对应的单工具**。此前几轮报告的"无删除特征""拉伸无拔模"
应更正为"能力存在于 plan 通道、单工具缺失"。本轮未实测，建议下轮验证，尤其是：
`feature_state` 要求"必须列出每一个受影响的依赖项，缺一个就拒绝整个 plan"——这个约束在复杂特征树上
使用成本很高，建议给出"自动展开依赖"的模式或返回可复制的依赖清单。

### P5 — 标签大小写报错（小问题，但报错文案已是正面范例）

`label = "mcA10c"` 被拒，报错为：
`Label must start with a lowercase letter, contain only [a-z0-9_], and be at most 28 characters; for example i001_part1`
——信息完整、给出示例，无需改动。

## 5. 其他观察与说明

### 5.1 本轮明确改善的地方（应当保留）

1. **多轮廓**：≤2 的硬限制消失，10 轮廓实测通过（圆/方/弧链三种形态）。
2. **拉伸失败报错**：现在带 `Detected native section: N closed contour(s), ... open end(s)` 和
   "The section carries open ends, so it is not a closed profile"——比 0.8.2 的纯 `-1` 好太多，本轮 P1 能被精确定位全靠它。
3. **`profile.arc_geometry`**：逐弧回报 `start_uv / end_uv / start_tangent_uv / end_tangent_uv / sweep_deg`，
   可以直接用来核对端点是否真的重合（我就是靠它确认了 D 的端点散开）。
4. **`profile.categories.near_tolerance`**：信号已经在，只是没接上动作（见 P1 建议 2）。
5. **preview**：建模 job 本轮全部 `written`，并带 `file_check` 逐项校验。

### 5.2 体积噪声的量级（给做严格校验的人的 caveat）

| 截面类型 | 相对误差 |
|---|---|
| 纯圆（解析曲线） | ~1e-14 |
| 多边形（矩形链） | −6.0e-7 |
| 弧链闭环 | +6.9e-7 |
| 弧链闭环（gear10 吸附版） | +3.5e-9 |

含直线段/多段拼接的截面，体积相对误差在 **1e-6 量级**（符号不定）。这不是缺陷，但做 ≤1e-7 级
验收判据时要留出余量；解析圆截面则可以放心按 1e-13 判。
