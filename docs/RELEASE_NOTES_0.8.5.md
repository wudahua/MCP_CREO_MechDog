# MCP_CREO_MechDog 0.8.5

0.8.5 交付 [DEV-051](work-items/DEV-051.md) 本轮已落地的实机改动和证据。折边方向的 `flip` 语义改变，并新增钣金体并入式实体增料的明确拒绝码，按项目规则属于 **MINOR 性质的接口变更**；按本次指定发布为 0.8.5。公开工具仍为 **94** 个。0.8.0—0.8.4 的提交、标签、Release 和附件均保持原样。

## 升级必读：折边方向

折边方向由原生元素 `PRO_E_SMT_FLANGE_SEC_FLIP` 控制。现在 `flip=false`（默认）表示**从选中面向外**，`flip=true` 表示反向。依赖旧方向假设的调用方必须检查所选面与 `flip` 值，并以几何包围盒、保存重载结果重新验收。1 mm 底板的两例折边实机均增加 **18 025.29 mm³**，Z 向增长 **79 mm**，保存重载核验通过；反向示例也已验证。0.8.4 的平铺结论属于旧实现当轮事实，不代表本版仍平铺。

## 本轮实机与支持边界

- T03 首壁五组已在 0.8.4 修复并实测通过，本版继承其范围；T02 弧方向 4/4、T06 新件倾斜草图 9/9、T07 多环替代夹具 3/3、T08A 预览文件 4/4 属 0.8.3 的指定证据，不重标为本轮重跑。
- T04 在本机 Creo 12.4.0.0 定案：普通件 add +400 mm³、钣金 cut −100 mm³；钣金体并入式实体 add 在重叠和非重叠位置均原生 `-1` 且元素错误为空。`new_body=true` 可生成独立实体（+500 mm³）。此组合现在于建模前返回 `SHEETMETAL_SOLID_ADD_UNSUPPORTED`，指引使用 `sheetmetal_wall`、`sheetmetal_flange` 或 `new_body=true`；`revolve` 增料未纳入该规则。
- T05/T11 四壁仅 **2/4**：第三道 `f_ny` 原生 `-1`、regeneration failed，`effect_status=rolled_back`，没有继续第四道。`relief` 被接受并回显，但与无释放的已成功折边体积和缺口面逐位相同，**不能宣称切料生效**。
- T08B body_counts **5/5**；T09A 组件业务标签 **4/4**；T09B 回转轴 **3/3**。T09B 同时发现单条用户中心线时 `section_centerline_count=3`，仍需修正。T12 沉孔/沉头 **3/3**，其中 180° 依输入契约拒绝。
- T13 `native_bundle` **不通过**：导出 `complete=false`、`files=1`、`missing=2`；巡检名 `▩C_...0001` 与磁盘名 `c_..._0.prt.1` 不同源。回导报 `SESSION_NAME_CONFLICT`。未猜测映射或放宽身份校验。
