# MCP_CREO_MechDog 0.8.0

DEV-051 0.7.0 反馈后续批次，MINOR。公开工具数仍为 94。此版把 T00、T01、T02—T09C、T11—T13 的已提交离线实现、调查和文档纳入同一源码交付；各项状态以 [阶段验收卡](development/DEV051-T01-ACCEPTANCE.md)及[发布记录](validation/RELEASE-0.8.0.md)为准。新增原生能力**尚未完成实机验收**，不能把可编译和单元通过解读为 Creo 建模成功。

## 新接口与修正

- 草图圆弧支持显式整数 `dir` 并回显原生弧几何。零扫角、整圆及非整数方向输入明确拒绝；原案多环与 30 段星形附件缺失，替代离线夹具不关闭原案。
- 钣金首壁校验和驱动面选择修正，冲突的深度／厚度参数在建模前拒绝，不再静默改写；法兰增加 `relief`（省略为 `none`）。四壁失败原案仍缺关键参数和实机复现。
- 孔增加可选原生沉孔、沉头参数，旧直孔请求保持原形。孔型、实际尺寸 ID、几何、修改及保存重载均待实机。
- 装配查询增加组件业务标签；已登记装配可显式导出 `native_bundle`，附逐件哈希、缺件及 `complete` 状态。真实新目录打开和嵌套引用闭包未验收。
- 回转结果增加实际轴几何查询回显；预览文件检查、body 计数与查询诊断也增加有界可观察信息。未知结果保持未知，不据诊断推断原案已修复。

## 升级与不兼容面

源码和九种子包须一起升级，核对各自 SHA256，使用目标 Creo 的匹配 SDK 重建执行器、重新安装 editable 包并重启 MCP 服务。`creo_capabilities` 应报告 0.8.0、94 个工具和正确运行路径。弧 `dir` 只接受严格整数；零扫角／整圆输入改为拒绝。钣金首壁冲突参数改为建模前拒绝，`relief` 默认 `none`。`native_bundle` 仅为显式装配导出格式，交付前检查 manifest 的 `complete`。详见[安装说明](INSTALL.md)和[迁移说明](MIGRATION.md)。
